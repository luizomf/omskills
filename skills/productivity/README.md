# Productivity

General workflow tools, not code-specific.

## User-invoked

- **[grill-me](./grill-me/SKILL.md)** - Run a grilling session without touching code or docs.
- **[handoff](./handoff/SKILL.md)** - Compact the current conversation into a handoff document so another agent can continue the work.
- **[teach](./teach/SKILL.md)** - Teach the user a new skill or concept over multiple sessions, using the current directory as a stateful teaching workspace.
- **[writing-great-skills](./writing-great-skills/SKILL.md)** - Reference for the vocabulary and design principles behind predictable skills.

## Model-invoked

- **[grilling](./grilling/SKILL.md)** - Reusable interview loop behind `grill-me`, `grill-with-docs`, `triage`, and `wayfinder`.
- **[write-a-skill](./write-a-skill/SKILL.md)** - Create new skills with proper structure, progressive disclosure, and bundled resources.

## Optional

- **[caveman](./caveman/SKILL.md)** - Ultra-compressed communication mode. Kept around, but not part of the default Codex manifest.
