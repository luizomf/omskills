---
name: research
description: Investigate a question using primary sources and save cited findings as one Markdown file in the repository. Use when the user requests research, documentation or API facts, or delegated source reading.
---

Delegate the research to a background worker through the active harness and continue other work while it runs. In Pi, follow [PI.md](PI.md).

Give the worker these requirements:

1. Answer the stated question using primary sources: official documentation, source code, specifications, or first-party APIs. Use a secondary source only to locate a primary source; cite the primary source for the resulting claim.
2. Write all findings to one Markdown file. Attach a source citation to every claim.
3. Use the repository's existing location and naming convention for research notes. If none exists, place the file somewhere sensible in the repository. Report the final path.
