# Triage labels

| Canonical triage role | GitHub label      | Meaning                                      |
| --------------------- | ----------------- | -------------------------------------------- |
| `needs-triage`        | `needs-triage`    | Maintainer evaluation is required            |
| `needs-info`          | `needs-info`      | Waiting for reporter or maintainer context   |
| `ready-for-agent`     | `ready-for-agent` | Fully specified and safe for an agent        |
| `ready-for-human`     | `ready-for-human` | Requires human implementation or judgment    |
| `wontfix`             | `wontfix`         | Will not be actioned                         |

Use exactly one canonical triage-role label on an issue at a time.
